# Dungeon Battle: Rise of Hero - OOP Progress Presentation

Fullscreen HTML presentation adapted from the repository's existing web presentation system.

## How to Open

Open `index.html` directly in a browser, or serve the folder locally if you prefer.

Recommended controls:

- Arrow keys / Page Up / Page Down / Space: navigate slides
- Mouse wheel: navigate slides
- Touch swipe: navigate on mobile/tablet
- `F`: toggle fullscreen
- `N`: toggle speaker notes

## Deck Content

The presentation is grounded in the current repository state:

- project overview and goals
- architecture and runtime flow
- OOP design and class relationships
- embedded code examples from the Java source
- current progress, challenges, and future work
- local screenshots plus royalty-free supporting assets

## Editable Files

- `data/content.json`: primary editable slide content
- `data/deck-data.js`: runtime wrapper generated from `content.json`
- `slides.js`: existing deck engine with small renderer extensions for diagrams, code, and showcases
- `styles.css`: shared deck theme plus targeted styles for the new slide types

## Assets

- `assets/images/`: screenshots and supporting visuals
- `assets/diagrams/`: generated architecture and UML SVGs
- `assets/icons/`: royalty-free Lucide icons
- `ASSET_SOURCES.md`: source URLs and license notes for downloaded assets
